# Data Dictionary

| Column | Description | Type / Units |
|---|---|---|
| state | U.S. state name | String |
| year | Year the data refers to | Integer (YYYY) |
| labor_force_participation_rate | % of working-age people with disabilities in the labor force | Float, percent |
| employment_rate | % of working-age people with disabilities who are employed | Float, percent |
| population_with_disability | Estimated number of people with a disability in the state | Integer, count |
