# disability-employment-by-state

State-level employment statistics for people with disabilities (2023)

## Contents
- `disability_employment_by_state.csv` — one row per U.S. state

## Use cases
- Comparing labor force participation and employment rates across states
- Identifying states with the largest gaps between participation and employment
- Combining with population data to estimate absolute numbers of 
  employed/unemployed people with disabilities

See `DATA_DICTIONARY.md` for column definitions
